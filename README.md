# Samathi101 Near Me (สาขาสถาบันพลังจิตตานุภาพใกล้ฉัน)

แอปพลิเคชันเว็บ (PWA) ออกแบบมาสำหรับการค้นหา "สาขาสถาบันพลังจิตตานุภาพ" ที่ใกล้เคียงพิกัดปัจจุบันของคุณที่สุด และช่วยอำนวยความสะดวกในการค้นหาสาขาทั่วประเทศได้อย่างรวดเร็วผ่านระบบแผนที่

🌐 **Live Demo:** [samathi101-near-me.pages.dev](https://samathi101-near-me.pages.dev/)

---

## 🎯 ฟีเจอร์หลัก (Features)

1. **ระบบระบุตำแหน่งและการนำทาง (Location & Navigation)**
   - ค้นหาสาขาที่อยู่ใกล้ตัวที่สุด 5 อันดับแรกโดยอัตโนมัติ (Locate Me) — ระยะทางเป็นเส้นตรง ไม่ใช่ระยะทางถนน
   - **Click-to-Call**: เบอร์โทรผู้ดูแลในหน้าข้อมูลสามารถกดโทรออกได้ทันทีบนมือถือ ☎️
   - เปิดนำทางผ่าน Google Maps ได้ทันทีจากป๊อปอัปแผนที่
   - **ลิงก์ตรงรายสาขา**: `?branch=35` เปิดหน้ารายละเอียดสาขานั้นทันที พร้อมปุ่มคัดลอก/แชร์ลิงก์ (ใช้ Web Share API บนมือถือ) 🔗

2. **ระบบแผนที่และพิกัดอัจฉริยะ (Interactive Cinematic Map)**
   - **Manual Configuration**: ล็อกมุมมองประเทศไทยให้ "เป๊ะ" ที่สุดผ่านไฟล์ `config.json` 🛰️
   - **Safe-Area Padding**: คำนวณพื้นที่การแสดงผลให้หลบ Header และ Bottom Sheet โดยอัตโนมัติ
   - แสดงจุดปักหมุดสาขาทั่วประเทศ พร้อมซูมไปยังจุดที่เกี่ยวข้องเมื่อทำการค้นหา
   - **แยกสาขาที่ยังไม่มีพิกัด**: สาขาที่ข้อมูลพิกัดเป็น 0,0 จะไม่ถูกปักหมุด (เดิมหมุดจะไปโผล่กลางมหาสมุทรแอตแลนติก) แต่ยังแสดงในหมวด "รอปรับพิกัด" พร้อมปุ่มค้นหาชื่อใน Google Maps เพื่อให้ยังติดต่อได้ และเห็นชัดว่าต้องเติมพิกัดสาขาไหนบ้าง

3. **แผงค้นหาและแสดงผลอัจฉริยะ (Adaptive Search)**
   - **Smart Group Search**: ค้นหาสาขาตามกลุ่มด้วยรหัส **"ก.x"** หรือ **"กลุ่ม x"** (เช่น พิมพ์ "ก.10" เพื่อดูสาขาทั้งหมดในกลุ่ม 10) 🔍
   - UI แบบ Bottom Sheet ที่ออกแบบมาเพื่อมือถือ (Mobile-First) โดยเฉพาะ (ใช้ `100dvh`)
   - ค้นหาข้อมูลครอบคลุม: ชื่อสาขา, เลขสาขา, กลุ่มสาขา, ภาค (`custom_region`), จังหวัด (ไทย/อังกฤษ), อำเภอ และตำบล
   - **แผนที่กรองตามผลค้นหา**: หมุดบนแผนที่จะเหลือเฉพาะสาขาที่ค้นเจอ แล้วซูมให้เห็นครบทุกจุดโดยอัตโนมัติ (หน่วง 250 ms เพื่อไม่ให้กระตุกตอนพิมพ์)
   - **ชิปกรองตามภาค**: กดกรองเฉพาะภาคที่สนใจได้ในคลิกเดียว และใช้ร่วมกับช่องค้นหาได้
   - **Marker Cluster**: รวมหมุดที่อยู่ใกล้กันเป็นกลุ่มเพื่อให้แผนที่อ่านง่ายและลื่นขึ้น (ถ้าโหลดปลั๊กอินไม่ได้จะ fallback เป็นหมุดเดี่ยวอัตโนมัติ)
   - รูปภาพสาขาแสดงในหน้ารายละเอียดแบบ lazy-load

## 🛠️ ระบบการตั้งค่าแผนที่ (Map Configuration & Admin Mode)

เรามีระบบที่ช่วยให้ผู้ดูแลสามารถปรับแต่งมุมมอง "มาตรฐาน" ของประเทศไทยได้ด้วยตัวเองโดยไม่ต้องแก้โค้ด:

1. **การเข้าสู่โหมด Admin:** เติม `?admin=1` ต่อท้าย URL (เช่น `index.html?admin=1`)
2. **การปรับแต่ง:** หมุน ซูม แผนที่จนได้มุมที่สวยที่สุด ระบบจะแสดง Lat, Lng และ Zoom ในแผงควบคุม HUD
3. **การบันทึก:** กดปุ่ม **"Save Current View"** เพื่อดาวน์โหลดไฟล์ `config.json` ชุดใหม่
4. **การนำไปใช้:** นำค่าในไฟล์ไปวางในโปรเจกต์และ Push ขึ้น Git แอปจะจำพิกัดนั้นถาวรครับ 🏆

---
4. **เทคโนโลยี PWA (Progressive Web App)**
   - สามารถกด "Add to Home Screen" ติดตั้งลงบนหน้าจอมือถือ/แท็บเล็ตได้ราวกับแอปพลิเคชันพื้นเมือง (Native App)
   - **Network-First Service Worker**: ระบบจัดการการดึงข้อมูลที่รับประกันว่าผู้ใช้จะได้โค้ดเวอร์ชันล่าสุดเสมอตอนที่ออนไลน์ แต่ยังสามารถเปิดใช้งานแอปแบบออฟไลน์ได้เวลาที่ขาดอินเทอร์เน็ต

5. **ระบบจัดการแคช (Cache Management)**
   - ควบคุมอายุข้อมูลด้วยไฟล์ `_headers` ของ Cloudflare เพื่อป้องกันอดีตไฟล์แคชค้างในตัวเบราว์เซอร์

---

## 🛠 เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend:** Vanilla HTML5, CSS3, JavaScript (ES6+)
- **Map Engine:** [Leaflet.js](https://leafletjs.com/) (OpenStreetMap API)
- **Deployment & Hosting:** Cloudflare Pages (ผสานการทำงานกับ GitHub Actions)
- **Environment:** มีชุดสคริปต์ Python ในโฟลเดอร์ `scripts/` สำหรับการจัดการข้อมูลและการ Mapping

---

## 🗄️ การจัดการข้อมูล (Data Management)

ข้อมูลสาขา (`branches.json`) ของโปรเจกต์นี้สามารถอัปเดตให้ทันสมัยได้เสมอผ่านชุดสคริปต์ในโฟลเดอร์ `scripts/` ดังนี้:

### 1. การดึงข้อมูลใหม่จากฐานข้อมูลหลัก (API)
ใช้เมื่อต้องการดึงข้อมูลสาขาล่าสุดจาก Server หลัก:
```bash
python3 scripts/fetch_and_process.py   # ขั้นตอนนี้จะล้าง group_id / custom_region
python3 scripts/update_branches.py     # ต้องรันต่อทันที เพื่อเติมกลุ่ม/ภาคกลับจาก Excel
```

> ⚠️ **ต้องรัน 2 คำสั่งนี้ติดกันเสมอ** เพราะ API ไม่มีฟิลด์ `group_id` และ `custom_region`
> ถ้ารันแค่คำสั่งแรกแล้ว commit จะทำให้ข้อมูลกลุ่มสาขาหายทั้งไฟล์

**เรื่อง Token:** endpoint `GET https://api.samathi101.com/branch/all/front` เป็น **public แล้ว ไม่ต้องใช้ token**
สคริปต์ยังรองรับ `SAMATHI_API_TOKEN` อยู่ เผื่อวันหนึ่ง API กลับมาบังคับ auth — วิธีเอา token มาใช้:

1. ล็อกอิน samathi101.com ด้วยบัญชี Google ที่มีสิทธิ์แอดมิน
2. เปิด DevTools → แท็บ **Network** → คลิกอะไรก็ได้ที่ยิงไป `api.samathi101.com`
3. ดูที่ **Request Headers** → คัดลอกค่าในบรรทัด `Authorization: Bearer eyJ...` ทั้งบรรทัด
4. `export SAMATHI_API_TOKEN='Bearer eyJ...'` แล้วรันสคริปต์

*Token เป็น Firebase ID token (project `will-power-prod`) **อายุแค่ 1 ชั่วโมง** ต้องคัดลอกใหม่ทุกครั้งที่ใช้ และห้าม commit ลง repo เด็ดขาด*

### 2. การอัปเดตกลุ่มสาขา (Excel Mapping)
ใช้เมื่อได้รับไฟล์ Excel อัปเดตกลุ่มสาขาจากทีมงาน ให้นำไฟล์ไปวางในโฟลเดอร์ `data/` แล้วรัน:
```bash
python3 scripts/update_branches.py
```
*สคริปต์นี้จะอ่านข้อมูลจาก Excel และนำไปเติมใน `branches.json` ให้โดยอัตโนมัติ (รองรับการรันซ้ำได้ตลอดเวลา)*

### 3. การตรวจสอบความสอดคล้อง (Consistency Check)
ใช้ตรวจสอบว่าข้อมูลในไฟล์ Excel ต่างๆ ในโฟลเดอร์ `data/` มีการระบุกลุ่มที่ขัดแย้งกันหรือไม่:
```bash
python3 scripts/check_consistency.py
```

## 🚀 การรันโปรเจกต์ (Local Development)

การรันโปรเจกต์นี้บนเครื่องคอมพิวเตอร์แบบออฟไลน์ ไม่จำเป็นต้องติดตั้ง Node.js หรือ build-tools ใดๆ เพียงแค่มี Local HTTP Server เช่น:

**หากมี Python:**
```bash
python -m http.server 8000
```
แล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:8000`

**หากใช้ VS Code:**
แนะนำให้ติดตั้ง Extension อย่าง **Live Server** และทำเพียงคลิกเปิดจากไฟล์ `index.html` ก็จะทำงานได้ทันที

## 🧪 การรันเทส (Tests)

ตัวเว็บไม่ต้องใช้ Node.js ในการ deploy แต่มีชุดเทสไว้กันบั๊กย้อนกลับ (regression) เวลาแก้โค้ด:

```bash
npm install   # ติดตั้ง jsdom (ครั้งแรกครั้งเดียว)
npm test
```

- `tests/app.test.js` — รัน `app.js` ใน jsdom โดย stub Leaflet ไว้ ตรวจการแยกสาขาที่ไม่มีพิกัด, การค้นหา, การกดการ์ด, หมุดบนแผนที่ และการ escape HTML
- `tests/sw.test.js` — จำลอง `caches`/`fetch` เพื่อตรวจว่า Service Worker ใช้งานออฟไลน์ได้จริง และไม่ล้มเมื่อ CDN ล่ม

*โฟลเดอร์ `node_modules/` ถูก ignore ไว้แล้วและไม่ถูก deploy ขึ้น Cloudflare Pages*

## ⚙️ ระบบ CI/CD (Continuous Deployment)

โปรเจกต์นี้ผูกระบบอัตโนมัติเข้ากับ **GitHub Actions** (ไฟล์ `.github/workflows/deploy.yml`)
ทุกครั้งที่มีการอัปเดตโค้ดลงบน branch `main` ระบบจะทำการ Deploy โค้ดใหม่ขึ้นสู่บัญชี **Cloudflare Pages** โดยทันที

**สิ่งสำคัญเมื่อนำไปใช้เอง (Environment Secrets):**
ต้องมีการตั้งค่าใน Repository Secrets ของ GitHub ดังนี้:
- `CF_API_TOKEN`: Cloudflare Global/API Token ที่มีสิทธิ์สั่งอัปเดตระบบ Pages
- `CF_ACCOUNT_ID`: Cloudflare Account ID

## 🔄 การตั้งค่า Redirect จากโดเมนเก่า

หากคุณต้องการย้ายผู้ใช้จากเว็บไซต์เดิม (เช่น `https://sumana.org/wpMap/`) มายังแอปใหม่นี้บน Cloudflare Pages แบบเนียนๆ (ผู้ใช้เข้าเว็บเก่าแล้วเด้งมาเว็บใหม่ทันที) และเป็นผลดีต่อ SEO แนะนำให้ใช้วิธีแก้ไขไฟล์ `.htaccess` บนเซิร์ฟเวอร์เก่า:

1. เข้าไปที่โฟลเดอร์ของเว็บไซต์เก่า (เช่นโฟลเดอร์ `wpMap`)
2. สร้างหรือแก้ไขไฟล์ชื่อ `.htaccess` (อย่าลืมจุดนำหน้า)
3. ใส่โค้ดนี้ลงไป:

```apache
Redirect 301 /wpMap https://samathi101-near-me.pages.dev/
```
*(หากใส่ในโฟลเดอร์ `wpMap` โดยตรง อาจใช้แค่ `Redirect 301 / https://...` ขึ้นอยู่กับการตั้งค่าโฮสติ้ง)*
