# พิกัดสาขาที่รอการยืนยัน

อัปเดตล่าสุด: 2026-08-13

เดิมมี **29 สาขา** ที่ข้อมูลพิกัดในระบบหลักเป็น `0,0` (คือยังไม่ได้กรอก) ทำให้หมุดไปตกกลางมหาสมุทรแอตแลนติก
และไม่ถูกนับใน "สาขาใกล้ฉัน" เลย

ทีมงานได้ค้นพิกัดจาก **OpenStreetMap** มาเติมให้ชั่วคราว **14 สาขา** และยังเหลือ **15 สาขา** ที่หาไม่ได้

> ⚠️ พิกัดทั้งหมดในตารางแรก **ยังไม่ได้รับการยืนยันจากสาขา** — ในแอปจะแสดงหมุดสีทองพร้อมข้อความ
> "พิกัดรอสาขายืนยัน" เพื่อไม่ให้ผู้ใช้เข้าใจผิดว่าเป็นข้อมูลที่ตรวจสอบแล้ว

### หมายเหตุรายสาขา

- **สาขาที่ 134 — กลุ่มบริษัท ปตท. จตุจักร กรุงเทพมหานคร**: OSM ไม่มีหมุดของตัวอาคาร ใช้จุดป้ายรถเมล์ 'ปตท. สำนักงานใหญ่' หน้าอาคารแทน คลาดเคลื่อนราว 200-300 ม.
- **สาขาที่ 176 — ม.เทคโนโลยีราชมงคลพระนคร กรุงเทพมหานคร**: มีหลายศูนย์ในกรุงเทพฯ เลือกศูนย์เทเวศร์ซึ่งเป็นที่ตั้งสำนักงานอธิการบดี — สาขาโปรดยืนยันว่าใช้ศูนย์ไหน
- **สาขาที่ 508 — มหาวิทยาลัยมหาสารคาม**: มมส. มี 2 เขตพื้นที่ (ขามเรียง / ในเมือง) เลือกขามเรียงซึ่งเป็นเขตหลัก — สาขาโปรดยืนยัน
- **สาขาที่ 512 — มหาวิทยาลัยราชภัฏราชนครินทร์**: มี 2 วิทยาเขต (เมืองฉะเชิงเทรา / บางคล้า) เลือกวิทยาเขตเมือง — สาขาโปรดยืนยัน

## วิธีส่งพิกัดกลับมา

1. เปิด Google Maps บนมือถือ ไปยืนที่หน้าสาขา
2. กดค้างที่ตำแหน่งบนแผนที่จนขึ้นหมุดสีแดง
3. ตัวเลขที่ขึ้นมา เช่น `13.7563, 100.5018` คือพิกัด — คัดลอกส่งให้ทีมงาน

## สำหรับผู้ดูแลระบบ

- ไฟล์ข้อมูล: `data/manual_coordinates.json`
- สคริปต์ค้นพิกัด: `python3 scripts/geocode_missing.py`
- พิกัดถูกนำไปรวมกับ `branches.json` ตอนรัน `scripts/update_branches.py` จึงไม่หายเวลาดึงข้อมูลใหม่จาก API
- **ถ้าระบบหลักมีพิกัดจริงแล้ว ระบบจะใช้ของระบบหลักเสมอ** และสคริปต์จะแจ้งให้ลบรายการนั้นออกจากไฟล์
